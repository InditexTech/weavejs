Brush tuning

Brush tuning

Settings, presets and scenarios that tune how the brush tool captures and draws strokes

Overview

The WeaveBrushToolAction has many settings that decide how pen, finger and mouse input becomes a stroke. The SDK publishes them as plain data, so an application can build controls for them, validate values and save configurations without knowing each setting in advance. The SDK itself has no user interface.

Settings come in two kinds:

  • capture settings belong to an input profile and change which points are saved for new strokes.

  • draw settings belong to a look. A look is saved with each stroke, so every user and every export draws that stroke the same way. Strokes saved without a look are drawn exactly as in earlier releases.

Every default below is the value of the legacy preset, which reproduces the behaviour of earlier releases. Nothing changes until an application selects another preset.

Some modes are introduced progressively. A setting whose mode is not implemented yet behaves as the legacy mode.

Import

import {
  BRUSH_TUNABLES,
  BRUSH_PROFILE_TUNABLES,
  BRUSH_LOOK_TUNABLES,
  BRUSH_PROFILE_PRESETS,
  BRUSH_LOOK_PRESETS,
  BRUSH_SCENARIOS,
  WeaveBrushPresetRegistry,
  validateBrushTunablePatch,
} from "@inditextech/weave-sdk";

The list of settings

Each entry of BRUSH_TUNABLES has this shape:

type WeaveBrushTunable = {
  key: string; // dotted path of the setting, unique inside its scope
  scope: "profile" | "look";
  path: string[];
  stage: "capture" | "pressure" | "stabilizer" | "finalize" | "touch" | "outline" | "curve" | "width" | "ends" | "detail";
  group: string; // heading a control is shown under
  kind: "capture" | "draw";
  type: "number" | "boolean" | "enum";
  default: number | boolean | string | null; // value of the legacy preset
  min?: number; max?: number; step?: number; integer?: boolean;
  options?: string[];
  nullable?: boolean;
  unit?: "px" | "ms" | "Hz" | "fraction" | "canvas units" | "count";
  help: string;
  advanced?: boolean; // show in an "advanced" section
};

A value outside a setting’s range or option list is invalid. validateBrushTunablePatch(scope, patch) returns the problems found in a partial profile or look; an empty list means the patch is valid.

Applying scenario A leaves every profile on its legacy preset and stores no look, so strokes are recorded and drawn exactly as in earlier releases.

const brush = weave.getActionHandler<WeaveBrushToolAction>("brushTool");

brush.applyScenario("B");

Custom presets

WeaveBrushPresetRegistry holds the factory presets and any custom ones. A factory preset cannot be changed or removed; copy it under a new id and change the copy. Custom presets live in memory: the application decides whether to save them.

const registry = new WeaveBrushPresetRegistry();

registry.copyProfilePreset("pen.desktop", "smooth", "my-wacom", "My Wacom");
registry.setProfilePreset("pen.desktop", "my-wacom", { pressure: { floor: 0.1 } });

brush.applyScenario(
  { ...BRUSH_SCENARIOS[1], id: "mine", profiles: { ...BRUSH_SCENARIOS[1].profiles, "pen.desktop": "my-wacom" } },
  registry
);

Saving and restoring a configuration

Method Description

exportConfig()

The four profiles and the look as a document with a version.

exportConfigJson()

The same document as JSON text.

importConfig(documentOrJson)

Restores a configuration. A document with an unsupported version or invalid values is rejected as a whole and nothing changes.

getLook() / setLook(patch | null)

The look saved on new strokes. null saves no look.

applyScenario(idOrScenario

Applies a scenario. Returns { applied, errors }.
