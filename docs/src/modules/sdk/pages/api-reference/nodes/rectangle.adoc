= WeaveRectangleNode
:description: Rectangle node API Reference

== Overview

The https://github.com/InditexTech/weavejs/blob/main/code/packages/sdk/src/nodes/rectangle/rectangle.ts[WeaveRectangleNode]
class represents a basic rectangular shape within the Weave.js canvas. It is one of the fundamental visual building blocks for
creating collaborative tools, diagrams, design layouts, and interactive content.

Built on top of Konva’s https://konvajs.org/api/Konva.Rect.html[Rect] class shape under the hood, the WeaveRectangleNode
offers a simple yet powerful primitive that supports full interaction, styling, and real-time synchronization.

Rectangles are ideal for:

* Building interactive visual elements (e.g., cards, sections, containers).
* Forming basic layout structures for more complex visual tools.
* Acting as a foundational primitive in diagrams, whiteboards, or flow-based applications.

Rectangle nodes support an optional *text label* that is displayed centred inside the shape.
The label can be edited interactively by double-clicking the rectangle while it is selected.
All label appearance properties (font, colour, alignment, padding, …) are configurable via the
`label*` props described below.

The class extends the xref:sdk:api-reference/nodes/node.adoc[WeaveNode] class

== Type

This node `nodeType` property value is `rectangle`.

== Label properties

The following props control the optional text label rendered inside the rectangle.
They map directly to `WeaveShapeLabelProps` and are all optional — omit them to use the defaults.

[cols="5*"]
|===
| Property | Type | Required | Default | Description

| mono:[labelText] | mono:[string] |  | mono:[""] | Text content of the label. Set to an empty string to hide the label.
| mono:[labelFontFamily] | mono:[string] |  | mono:["Arial, sans-serif"] | CSS font-family string for the label text.
| mono:[labelFontSize] | mono:[number] |  | mono:[14] | Font size of the label text in pixels.
| mono:[labelFontStyle] | mono:[string] |  | mono:["normal"] | Font style for the label. Accepts CSS font-style/weight keywords or a numeric weight (e.g. "normal", "bold", "italic", "bold italic", "700").
| mono:[labelFontVariant] | mono:[string] |  | mono:["normal"] | CSS font-variant for the label (e.g. "normal", "small-caps").
| mono:[labelTextDecoration] | mono:[string] |  | mono:[""] | CSS text-decoration for the label (e.g. "underline", "line-through").
| mono:[labelFill] | mono:[string] |  | mono:["#000000"] | Colour of the label text in hex format (e.g. #RRGGBBAA).
| mono:[labelAlign] | mono:[string] |  | mono:["center"] | Horizontal alignment of the label text ("left", "center", "right").
| mono:[labelVerticalAlign] | mono:[string] |  | mono:["middle"] | Vertical alignment of the label text ("top", "middle", "bottom").
| mono:[labelLetterSpacing] | mono:[number] |  | mono:[0] | Letter spacing for the label text in pixels.
| mono:[labelLineHeight] | mono:[number] |  | mono:[1] | Line-height multiplier for the label text.
| mono:[labelPaddingX] | mono:[number] |  | mono:[8] | Horizontal inset (padding) in pixels applied on each side of the label area.
| mono:[labelPaddingY] | mono:[number] |  | mono:[8] | Vertical inset (padding) in pixels applied on the top and bottom of the label area.
|===
