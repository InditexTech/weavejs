= WeaveStrokeNode
:description: Stroke node API Reference

== Overview

The https://github.com/InditexTech/weavejs/blob/main/code/packages/sdk/src/nodes/stroke/stroke.ts[WeaveStrokeNode]
class represents a multi-point continuous line or path on the Weave.js canvas. It is a versatile and essential node type for
building tools like freehand drawing.

Built on top of Konva’s https://konvajs.org/api/Konva.Shape.html[Shape] class shape under the hood, the WeaveStrokeNode
offers full control over the line’s geometry, style, and behavior—all synchronized in real time across users.

The class extends the xref:sdk:api-reference/nodes/node.adoc[WeaveNode] class

== Type

This node `nodeType` property value is `stroke`.

== Import

[source,shell]
----
import { WeaveStrokeNode } from "@inditextech/weave-sdk";
----

== Instantiation

[source,ts]

new WeaveStrokeNode(params?: WeaveStrokeNodeParams);

== Parameters

For `WeaveStrokeNodeParams`:

[cols="4*"]
|===
| Property | Type | Required | Description

| mono:[config] | mono:[Partial<WeaveStrokeProperties>] | label:green[Required] | Config parameters for the node.
|===

For `WeaveStrokeProperties`:

[cols="5*"]
|===
| Property | Type | Required | Default | Description

| mono:[splineResolution] | mono:[number] |  | mono:[8] | Minimum number of subdivisions used for a curved span of the smoothed curve. Longer spans are subdivided further, by arc length, so that rendered smoothness does not depend on how far apart the recorded points happen to be.
| mono:[splineTargetEdge] | mono:[number] |  | mono:[1] | Target length, in canvas units, of a single rendered edge. Lower values produce a smoother silhouette at the cost of proportionally more rendered vertices.
| mono:[splineMaxSteps] | mono:[number] |  | mono:[48] | Upper bound on the subdivisions used for one span, so an unusually long span cannot inflate the vertex count without limit.
| mono:[resamplingSpacing] | mono:[number] |  | mono:[2] | Minimum spacing between the control points fed to the spline. Applied after simplification, so it mainly guards against duplicate and near-duplicate samples.
| mono:[isEraser] | mono:[boolean] |  | mono:[false] | Whether the stroke behaves as an eraser.
|===

[NOTE]
====
`splineResolution` and `resamplingSpacing` were previously accepted but
ignored — the renderer used hardcoded values regardless. They now take
effect, so a node that passed non-default values will render differently
than it did before.
====

== Default values

[source,ts]
----
const WEAVE_STROKE_NODE_DEFAULT_CONFIG = {
  splineResolution: 8,
  splineTargetEdge: 1,
  splineMaxSteps: 48,
  resamplingSpacing: 2,
  isEraser: false,
};
----
