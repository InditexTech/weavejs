= WeavePolygonNode
:description: Polygon node API Reference

== Overview

The https://github.com/InditexTech/weavejs/blob/main/code/packages/sdk/src/nodes/polygon/polygon.ts[WeavePolygonNode]
class represents a polygon shape within the Weave.js canvas.

Unlike the `WeaveRegularPolygonNode`, which uses Konva's built-in `RegularPolygon` primitive,
`WeavePolygonNode` is drawn via explicit vertex points (`points: WeavePolygonPoint[]`). This enables
arbitrary convex polygon shapes and precise inside-stroke rendering that never exceeds the shape boundary.

The node also supports an inline text label whose bounding box is derived from the polygon's
`innerRect` — the largest axis-aligned rectangle that fits inside the shape.

The class extends the xref:sdk:api-reference/nodes/node.adoc[WeaveNode] class.

== Label engine

By default the label is rendered with Konva's text and edited through a DOM textarea overlay (`legacy`).
Set `config.label.engine` to `native` to render the label with the on-canvas text engine and edit it
with the native editing session instead: no DOM overlay, and caret and selection are drawn on the canvas.

[source,ts]
----
new WeavePolygonNode({ config: { label: { engine: "native" } } });
----

Both engines read and write the same `labelText` and `label*` props, so clients using different engines
can edit the same document. The `native` engine enables rich text in labels (bold, italic, underline, lists, alignment). Formatted content is stored in the optional `labelBlocks` prop, and `labelText` always holds the plain text, so the `legacy` engine shows the plain text.

== Label edit events

With the `native` label engine the node emits `onEnterShapeLabelEditMode` when a label edit session starts and
`onExitShapeLabelEditMode` when it ends. Exit receives `{ node: Konva.Group }`; enter also receives the live
`session`, so an app can build a formatting toolbar by running format commands on it. While editing,
`onShapeLabelFormatChange` receives `{ node, format }` whenever the selection format changes.
The `legacy` engine does not emit them.

== Type

This node `nodeType` property value is `polygon`.

== Presets

The polygon node ships with six built-in presets available via the exported constant
`WEAVE_POLYGON_PRESETS`. Each preset defines normalized vertex positions and an inner
bounding rectangle used for label placement.

[cols="3*"]
|===
| Preset ID | Label | Sides

| `triangle` | Triangle | 3
| `diamond` | Diamond | 4
| `pentagon` | Pentagon | 5
| `hexagon` | Hexagon | 6
| `octagon` | Octagon | 8
| `decagon` | Decagon | 10
|===
