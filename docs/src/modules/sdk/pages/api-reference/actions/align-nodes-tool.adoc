= WeaveAlignNodesToolAction
:description: Align selected nodes tool

== Overview

The https://github.com/InditexTech/weavejs/blob/main/code/packages/sdk/src/actions/align-nodes-tool/align-nodes-tool.ts[WeaveAlignNodesToolAction]
class that allows users to align selected nodes vertically or horizontally.

The class extends the xref:sdk:api-reference/actions/action.adoc[WeaveAction] class.

== Name

This action `name` property value is `alignNodesTool`.

----
import { WeaveAlignNodesToolAction } from "@inditextech/weave-sdk";
----
