= WeaveBrushToolAction
:description: Paint freeform strokes on the canvas

== Overview

The https://github.com/InditexTech/weavejs/blob/main/code/packages/sdk/src/actions/brush-tool/brush-tool.ts[WeaveBrushToolAction]
class that enables users to draw freeform strokes on the canvas using a brush tool. It lets users click and drag across the canvas
to create a smooth, continuous path—perfect for sketching, annotating, or freehand drawing within a collaborative environment.

Each stroke is recorded as a xref:sdk:api-reference/nodes/line.adoc[WeaveLineNode], synchronized across all connected users in real time.

The class extends the xref:sdk:api-reference/actions/action.adoc[WeaveAction] class.

== Name

This action `name` property value is `brushTool`.

== Type

This node `nodeType` property value is `stroke`.

== Parameters

For `WeaveBrushToolActionParams`:

[cols="4*"]
|===
| Property | Type | Required | Description

| mono:[config] | mono:[Partial<WeaveBrushToolActionProperties>] | label:green[Required] | Config parameters for the tool.
|===

For `WeaveBrushToolActionProperties`:

[cols="5*"]
|===
| Property | Type | Required | Default | Description

| mono:[interpolationSteps] | mono:[number] |  | mono:[10] | Number of interpolation steps for smooth curve on touch devices.
| mono:[simplifyTolerance] | mono:[number] |  | mono:[0.5] | Tolerance, in canvas units, of the Douglas-Peucker simplification applied once when a stroke is finalized. While a stroke is being drawn every recorded sample is rendered; on release the point list is simplified before being persisted, so this value governs how much fidelity a finished stroke gives up. Lower values keep a finished stroke closer to the path drawn, at the cost of more points stored per stroke.
|===

== Default values

[source,ts]
----
const BRUSH_TOOL_DEFAULT_CONFIG = {
  interpolationSteps: 10,
  simplifyTolerance: 0.5,
};
----
