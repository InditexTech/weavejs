= WeaveMeasureToolAction
:description: Add measure nodes to the canvas

== Overview

The https://github.com/InditexTech/weavejs/blob/main/code/packages/sdk/src/actions/measure-tool/measure-tool.ts[WeaveMeasureToolAction]
class that allows users to add measure to the canvas by click-and-click to define the measure points.

The class extends the xref:sdk:api-reference/actions/action.adoc[WeaveAction] class.

== Name

This action `name` property value is `measureTool`.

----
import { WeaveMeasureToolAction } from "@inditextech/weave-sdk";
----
