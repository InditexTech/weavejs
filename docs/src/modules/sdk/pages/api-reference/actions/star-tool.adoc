= WeaveStarToolAction
:description: Add a star to the canvas

== Overview

The https://github.com/InditexTech/weavejs/blob/main/code/packages/sdk/src/actions/star-tool/star-tool.ts[WeaveStarToolAction]
class that allows users to create star shapes on the canvas by clicking
and dragging. It provides a smooth, intuitive way to add structured, resizable
star elements .

Each interaction results in the creation of a xref:sdk:api-reference/nodes/star.adoc[WeaveStarNode],
added to the shared state and synchronized across all users.

The class extends the xref:sdk:api-reference/actions/action.adoc[WeaveAction] class.

== Name

This action `name` property value is `starTool`.

== Import

[source,shell]
----
import { WeaveStarToolAction } from "@inditextech/weave-sdk";
----

== Instantiation

[source,ts]
----
new WeaveStarToolAction();
----
