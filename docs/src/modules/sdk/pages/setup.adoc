= Setup
:description: Weave.js SDK API setup

== Dependencies

This package is dependant on:

* xref:sdk:index.adoc[Weave.js SDK] package
* xref:types:index.adoc[Weave.js types] package

== Installation

[source,shell]
----
npm install @inditextech/weave-sdk
----

[NOTE]
====
All Weave.js packages are published as ES modules only. Use `import` to load them. Loading them with `require()` from CommonJS code needs Node.js 20.19+ or 22.12+, the versions that support `require()` of ES modules.
====
