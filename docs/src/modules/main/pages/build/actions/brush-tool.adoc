= Brush Tool
:description: Paint freeform strokes on the canvas

image::actions/brush-tool-poster-light.png[A freehand stroke is drawn on the canvas: the Brush tool is picked in the toolbar and dragged along a wave then the stroke is selected,width=960,height=540,role="weave-demo weave-demo--brush-tool"]
== Introduction

This action enables users to paint freeform strokes on the canvas, similar to a
digital brush. Unlike the xref:main:build/actions/pen-tool.adoc[Pen Tool] action,
which focuses on clean vector lines, the *WeaveBrushToolAction* emphasizes style,
thickness, and expressive drawing, creating xref:main:build/nodes/line.adoc[Line] nodes
with a more natural, hand-drawn feel.

It’s ideal for sketching, highlighting, or adding visual flair to collaborative
sessions.

== Dependencies

This action needs registered on the Weave instance the following elements:

* xref:main:build/nodes/line.adoc[Line] node

== Usage

=== Import the Action
Start by importing the action:

[source,ts]
----
import { WeaveBrushToolAction } from "@inditextech/weave-sdk";
----

=== Register the Action
Then register the action on the xref:sdk:api-reference/weave/index.adoc[Weave] class instance.

[source,ts]
----
const instance = new Weave({
  ...
  actions: [
    ...,
    new WeaveBrushToolAction(), // <.>
  ]
})
----
<.> Added in this step.

=== Setup the action trigger
Setup on a button or any element on the UI the user can interact with on the action event:

[source,ts]
----
instance.triggerAction("brushTool");
----


For example on a button on React:

[source,tsx]
----
import React from "react";
import { useWeave } from "@inditextech/weave-react";

const MyBrushToolTriggerComponent = () => {
  const instance = useWeave((state) => state.instance);

  const triggerTool = React.useCallback(() => {
    instance.triggerAction("brushTool");
  }, [instance]);

  return <button onClick={triggerTool}>Brush Tool</button>;
};
----

=== Trigger the action
Finally a final user trigger the UI element that launches the action.


When active the user:

* *Click-press* or *Touch-press* on the canvas, to define a brush line.

Then the freeform line is added to the canvas as a fully functional node—ready.
This action integrates seamlessly with Weave.js's real-time state system,
ensuring the new element appears instantly for all connected users.

== Pens

The tool can draw with a named pen, called an *instrument*. Select one on the action:

[source,ts]
----
const brush = instance.getActionHandler<WeaveBrushToolAction>("brushTool");

brush.setInstrument("highlighter"); // pencil, pen, brush, fountainPen, fineliner, marker or highlighter
----

New strokes then take the look of that pen. If you never select one, the tool draws as before. See
xref:sdk:api-reference/actions/brush-tool.adoc#instruments[the API reference] for what each instrument does.
