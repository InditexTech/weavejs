= Rectangle
:description: Draw a rectangle on the canvas

image::nodes/rectangle.png[Rectangle on the Weave.js showcase,role="zoom-in"]

The Rectangle node is a simple, versatile primitive shape used to render rectangular
elements on the canvas. Built on top of Konva’s https://konvajs.org/api/Konva.Rect.html[Rect],
it supports customizable properties such as position, size, fill color, stroke, corner radius,
and more.

Rectangle nodes are often used as building blocks for UI components, layout guides,
or user-created nodes. They can also respond to interactions like dragging, resizing,
or selection.

== Usage

=== Import the Node
Start by importing the node:

[source,ts]
----
import { WeaveRectangleNode } from "@inditextech/weave-sdk";
----

=== Register the Node
Then register the node on the xref:sdk:api-reference/weave/index.adoc[Weave] class instance.

[source,ts]
----
const instance = new Weave({
  ...
  nodes: [
    ...,
    new WeaveRectangleNode(), // <.>
  ]
})
----
<.> Added in this step.

=== Use the node
Once the node is registered you can use it on xref:main:build/actions/index.adoc[Actions] or
xref:main:build/plugins/index.adoc[Plugins] or even other xref:main:build/nodes/index.adoc[Nodes].

We provide an action named xref:main:build/actions/rectangle-tool.adoc[Rectangle Tool] that
allows users to add Rectangle nodes to the application.
