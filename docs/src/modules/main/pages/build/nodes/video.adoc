= Video
:description: Render a video on the canvas

image::nodes/video.png[Image on Weave.js showcase,role="zoom-in"]

The Video Node allows you to render and play videos directly onto the canvas. Built on top
of Konva’s https://konvajs.org/api/Konva.Image.html[Image] shape, and https://konvajs.org/api/Konva.Animation.html[Konva Animation]
it supports properties play, pause and progress tracking.

== Usage

=== Import the Node
Start by importing the node:

[source,ts]
----
import { WeaveVideoNode } from "@inditextech/weave-sdk";
----

=== Register the Node
Then register the node on the xref:sdk:api-reference/weave/index.adoc[Weave] class instance.

[source,ts]
----
const instance = new Weave({
  ...
  nodes: [
    ...,
    new WeaveVideoNode(), // <.>
  ]
})
----
<.> Added in this step.

=== Use the node
Once the node is registered you can use it on xref:main:build/actions/index.adoc[Actions] or
xref:main:build/plugins/index.adoc[Plugins] or even other xref:main:build/nodes/index.adoc[Nodes].

We provide an action named xref:main:build/actions/video-tool.adoc[Video Tool] that allows
users to add Video (one-by-one) nodes to the application.
