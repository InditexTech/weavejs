= Star
:description: Draw a star on the canvas

image::nodes/star.png[Star on Weave.js showcase,role="zoom-in"]

The Star node is a simple, versatile primitive shape used to render star
elements on the canvas. Built on top of Konva’s https://konvajs.org/api/Konva.Star.html[Star],
it supports customizable properties such as amount of points, position, inner and outer radius, fill color, stroke, radius (on both axis),
and more.

They can also respond to interactions like dragging, resizing,
or selection.

== Usage

=== Import the Node
Start by importing the node:

[source,ts]
----
import { WeaveStarNode } from "@inditextech/weave-sdk";
----

=== Register the Node
Then register the node on the xref:sdk:api-reference/weave/index.adoc[Weave] class instance.

[source,ts]
----
const instance = new Weave({
  ...
  nodes: [
    ...,
    new WeaveStarNode(), // <.>
  ]
})
----
<.> Added in this step.

=== Use the node
Once the node is registered you can use it on xref:main:build/actions/index.adoc[Actions] or
xref:main:build/plugins/index.adoc[Plugins] or even other xref:main:build/nodes/index.adoc[Nodes].

We provide two actions:

* xref:main:build/actions/text-tool.adoc[Star Tool] that allows users to add Star nodes
to the application.
