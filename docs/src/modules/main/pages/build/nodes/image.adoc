= Image
:description: Render images on the canvas

image::nodes/image.png[Image on Weave.js showcase,role="zoom-in"]

The Image Node allows you to render images directly onto the canvas. Built on top
of Konva’s https://konvajs.org/api/Konva.Image.html[Image] shape, it supports
properties like position, scale, opacity, and filters.

Image nodes are perfect for adding visual references, icons, or user-uploaded media
to your collaborative canvas. They supporting selection, resizing, and drag-and-drop—and
and can be extended with plugins for features like cropping, masking, or annotations.

== Usage

=== Import the Node
Start by importing the node:

[source,ts]
----
import { WeaveImageNode } from "@inditextech/weave-sdk";
----

=== Register the Node
Then register the node on the xref:sdk:api-reference/weave/index.adoc[Weave] class instance.

[source,ts]
----
const instance = new Weave({
  ...
  nodes: [
    ...,
    new WeaveImageNode(), // <.>
  ]
})
----
<.> Added in this step.

=== Use the node
Once the node is registered you can use it on xref:main:build/actions/index.adoc[Actions] or
xref:main:build/plugins/index.adoc[Plugins] or even other xref:main:build/nodes/index.adoc[Nodes].

We provide an action named xref:main:build/actions/image-tool.adoc[Image Tool] that allows
users to add Image (one-by-one) nodes to the application.

== Flip an image

Image nodes can be flipped horizontally and vertically without generating a new asset:

[source,ts]
----
const imageNode = instance.getStage().findOne("#imageId") as Konva.Group;

instance.flipImage(imageNode, { axis: "horizontal" });
instance.flipImage(imageNode, { axis: "vertical" });

// or directly on the node
imageNode.flipHorizontal();
imageNode.flipVertical();
----

* Both axes are independent: the state persists them as the `flipX` and `flipY` booleans.
* Flipping the same axis twice restores the original image.
* Position, size, rotation and stacking order are not changed, and each flip is a single undo / redo step.
* The flip is kept when resizing, rotating, cropping, grouping, copy / pasting and when rendering on the server.
* Calling it while the image is being cropped has no effect.

See the xref:sdk:api-reference/nodes/image.adoc[WeaveImageNode API reference] for details.
