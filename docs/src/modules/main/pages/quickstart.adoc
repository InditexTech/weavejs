= Quickstart
:description: Build a real-time collaborative canvas application in minutes

*Weave.js* is a framework for building collaborative visual tools. It's composable, extendable, and includes a CLI for quickly scaffolding projects.

In this quickstart, you will learn how to set up your first real-time collaborative canvas project with Weave.js.

image::sample-app.gif[Sample Weave.js app,role="zoom-in"]

== Prerequisites

Before you begin, ensure you meet the xref:main:requirements.adoc[requirements].

== What you will set up

* An xref:main:application-structure.adoc#backend-artifact[Express backend server] that handles real-time synchronization using a Weave.js Store provider.
* A xref:main:application-structure.adoc#frontend-artifact[Next.js frontend application] that uses Weave.js to render a collaborative canvas with live updates.

== Step by step

=== 1. Scaffold the backend project

First, create the backend server that will handle all the real-time synchronization using a Weave.js Store provider.
In this case, use the xref:main:build/stores/websockets-store.adoc[Weave.js Store WebSockets].

Open a terminal in your preferred folder and execute the following command:

[tabs]
--
[tab,label="pnpm"]
****
[source,bash]
----
pnpm create weave-backend-app
----
****

[tab,label="npm"]
****
[source,bash]
----
npm create weave-backend-app
----
****

[tab,label="yarn"]
****
[source,bash]
----
yarn create weave-backend-app
----
****
--

The CLI will prompt you with the following:

. *Project name:*  The folder name for the backend project (e.g. `my-service`).
. *Select the store:*  For this quickstart, select the store named:
+
*Express.js: Weave.js Websockets Store*
. *Install dependencies automatically:* Select *YES*.  This will install the necessary dependencies of the project.

Once complete, start the server:

[tabs]
--
[tab,label="pnpm"]
****
[source,bash]
----
cd [backend-project-name]
pnpm run dev
----
****

[tab,label="npm"]
****
[source,bash]
----
cd [backend-project-name]
npm run dev
----
****

[tab,label="yarn"]
****
[source,bash]
----
cd [backend-project-name]
yarn run dev
----
****
--

This will start the backend server at `http://localhost:8080`.

To verify everything is running correctly, open a browser and enter the URL `http://localhost:8080/api/v1/health`.

You should see the following response:

[source,json]
----
{ "status": "OK" }
----

=== 2. Scaffold the frontend project
Now, create the frontend application on top of Next.js and powered by Weave.js.
This project will render the UI and canvas with live updates.

Open a new terminal in the same parent folder as the backend project and execute the following command:

[tabs]
--
[tab,label="pnpm"]
****
[source,bash]
----
pnpm create weave-frontend-app
----
****

[tab,label="npm"]
****
[source,bash]
----
npm create weave-frontend-app
----
****

[tab,label="yarn"]
****
[source,bash]
----
yarn create weave-frontend-app
----
****
--

The CLI will prompt you with the following:

. *Project name:*  The folder name for the frontend project (e.g. `my-app`).
. *Select the store:*  For this quickstart, select the store named:
+
*Express.js: Weave.js Websockets Store*
. *Install dependencies automatically:* Select *YES*.

Once complete, start the frontend application:

[tabs]
--
[tab,label="pnpm"]
****
[source,bash]
----
cd [frontend-project-name]
pnpm run dev
----
****

[tab,label="npm"]
****
[source,bash]
----
cd [frontend-project-name]
npm run dev
----
****

[tab,label="yarn"]
****
[source,bash]
----
cd [frontend-project-name]
yarn run dev
----
****
--

This will start the Next.js frontend application at `http://localhost:3030`.

.Self-signed certificate warning
[NOTE]
====
When running `npm run dev`, you might see a warning about self-signed certificates.
This is expected. Next.js is setting up HTTPS for local development, and may prompt for your system password.
It is a one-time setup.
====

Open a browser and navigate to `http://localhost:3030`.
You should see the room entry page (Next.js may take a moment to compile):

image::enter-room.png[Enter room page of the Weave.js project,role="zoom-in"]

.Join a room and interact with the canvas
To start using the canvas, follow these steps:

. Enter the room name you want to join.
. Type your username.
. Press the *ENTER* button.

Once the room is loaded (note that pages may take some time to compile), you should see the following screen:

image::room.png[Room page of the Weave.js project,role="zoom-in"]

Add shapes, draw elements, or interact with objects on the canvas.
Changes are synchronized in real time across all participants in the room.
