== 🔷 Clickable text.

*Release date:* September 9, 2026

This release lets a text node carry a URL, turning the whole text into a *clickable link*.

== Changes

=== Hyperlinks on Text Nodes

A text node can now carry a URL. When defined, the *whole text is clickable* and opens the link.

See xref:main:build/nodes/text.adoc[Text] for the node and its `link` property.

https://github.com/InditexTech/weavejs/issues/1167[https://github.com/InditexTech/weavejs/issues/1167]
