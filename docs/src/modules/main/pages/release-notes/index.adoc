= Release notes
:description: Discover what's new in Weave.js

What changed for users in each release, and how to upgrade. Every release gets a page, whatever its type: major, minor, patch or hotfix. The current major lists all of its versions. Earlier majors list their `.0.0` release, their minors with user-facing changes and their last patch; every other release is in the xref:main:changelog/index.adoc[Changelog].
