= Release notes
:description: Discover what's new in Weave.js

Release notes cover every *major* and *minor* release, and describe what changed for users and
how to upgrade. Patch releases (`X.Y.Z` with `Z` above 0) have no page of their own, and neither
do minors with no user-facing change. Both are listed in the xref:main:changelog/index.adoc[Changelog].
