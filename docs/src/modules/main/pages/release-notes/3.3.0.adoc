*Release date:* March 18, 2026

A small drawing improvement for stroke-based tools.

== Changes

=== Lock on Angles While Holding Shift

The stroke tool, its aliases such as the arrow tool, and the single-stroke node can lock on angles while Shift is pressed.

https://github.com/InditexTech/weavejs/issues/989[https://github.com/InditexTech/weavejs/issues/989]
