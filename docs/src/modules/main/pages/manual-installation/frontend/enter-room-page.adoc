= Enter Room page
:description: Learn how to set up the Enter Room page on Next.js

In this guide, you will build the *Enter Room page*:

image::enter-room-manual.png[Enter room page,role="zoom-in"]

This page allows users to define the room they wish to join and set their username.

== Prerequisites

Before you begin, ensure that you have completed the xref:main:manual-installation/frontend/enter-room-page.adoc[frontend installation] guide, up to the _"Set up the Enter Room page"_ step.

== Step by step

To set up the *Enter Room* page in your Next.js project, follow these steps:

=== 1. Install the UI building block components

Set up the necessary https://ui.shadcn.com/docs[Shadcn/UI] components for the *Enter Room* page.

Use the https://ui.shadcn.com/docs/cli[Shadcn/UI CLI] and accept all the default options.

From the project root folder, follow these steps:

* Install the https://ui.shadcn.com/docs/components/form[Form] component:
+
[source,shell]
----
npx shadcn@latest add form
----
* Install the https://ui.shadcn.com/docs/components/input[Input] component:
+
[source,shell]
----
npx shadcn@latest add input
----
