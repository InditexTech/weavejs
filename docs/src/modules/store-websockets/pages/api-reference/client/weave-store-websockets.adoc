= WeaveStoreWebsockets
:description: API reference for WeaveStoreWebsockets class

== Overview

The WeaveStoreWebsockets class is a client-side store implementation in the Weave.js ecosystem
that enables real-time collaboration using WebSockets. It connects to a compatible WebSocket
server—such as xref:store-websockets:api-reference/server/weave-websockets-server.adoc[WeaveWebsocketsServer]
to sync shared canvas state across all connected users.

Built on top of Yjs and y-websocket, it acts as a bridge between the client-side Weave.js app and the
remote backend, handling updates, awareness (presence), and document syncing with minimal setup.

== Import

[source,shell]
----
import { WeaveStoreWebsockets } from "@inditextech/weave-store-websockets/client";
----

== Instantiation

[source,ts]
----
const store = new WeaveStoreWebsockets(initialRoomData: Uint8Array | FetchInitialState | undefined, storeOptions: WeaveStoreOptions, websocketOptions: WeaveStoreWebsocketsOptions);
----

== Parameters

[cols="5*"]
|===
| Property | Type | Required | Default | Description

| mono:[initialRoomData] | mono:[Uint8Array \| FetchInitialState \| undefined] | label:green[Required] |  | If the room is not new, the actual data (snapshot) of the room in binary form.
| mono:[storeOptions.getUser] | mono:[() => WeaveUser] | label:green[Required] |  | A function that returns a WeaveUser as definition of the metadata of the user that connects to a room
| mono:[storeOptions.undoManagerOptions] | mono:[WeaveUndoManagerOptions] |  |  | An object that defines the Undo-Redo manager options
| mono:[websocketOptions.roomId] | mono:[string] | label:green[Required] |  | Room id that we want to join
| mono:[websocketOptions.wsOptions] | mono:[{ serverUrl: string; }] | label:green[Required] |  | WebSocket underlying client properties
| mono:[websocketOptions.callbacks] | mono:[WeaveStoreWebsocketsCallbacks] |  | mono:[{}] | Callbacks defined for the instance
|===

== Events

=== onStateChange

[source,ts]
----
onStateChange: WeaveStoreOnStateChangeEvent;
----

The `onStateChange` event is called when the shared-state changes.

=== onRoomLoaded

[source,ts]
----
onRoomLoaded: WeaveStoreOnRoomLoadedEvent;
----

The `onRoomLoaded` event is called when the room shared-state is loaded.

=== onUndoManagerStatusChange

[source,ts]
----
onUndoManagerStatusChange: WeaveStoreOnUndoRedoChangeEvent;
----

The `onUndoManagerStatusChange` event is called when the undo/redo manager changes. It is also emitted when a room connection begins (on every `connect()` call), resetting all stack counts to `0` and both `canUndo` and `canRedo` to `false`.

=== onNodeChange

[source,ts]
----
onNodeChange: WeaveStoreOnNodeChangeEvent;
----

The `onNodeChange` event is called when there is a single node selected and the node changes.

== Methods

=== connect

[source,ts]
----
connect(): Promise<void>
----

The `connect` method is called when an user tries to join a room.

=== disconnect

[source,ts]
----
disconnect(): Promise<void>
----

The `disconnect` method is called when an user leaves a room.

=== setAwarenessInfo

[source,ts]
----
setAwarenessInfo(field: string, value: unknown): void
----

This method set awareness information, for example if you want to inform the metadata of
an user that connected to the room, or to send the pointer information of that user to the
other peers.
