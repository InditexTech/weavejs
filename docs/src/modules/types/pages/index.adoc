= Overview
:description: Getting started with Weave.js TypeScript types

The `@inditextech/weave-types` package provides the shared TypeScript types and
constants used across the entire Weave.js ecosystem. It acts as a foundational
library that standardizes how data structures, node definitions, actions, plugins,
and stores are typed and referenced throughout your application and related packages.

Weave.js types package offers definitions for:

[cards]
====
[card]
.xref:types:api-reference/constants.adoc[Constants]
Definitions of all the constants used on the Weave.js ecosystem.

[card]
.xref:types:api-reference/types.adoc[Types]
Definitions of all the TypeScript types used on the Weave.js ecosystem.
====
